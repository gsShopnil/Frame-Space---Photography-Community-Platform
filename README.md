# FrameSpace

**A Community Beyond the Frame.**

FrameSpace is a photography community platform designed to connect photographers, showcase visual stories, and encourage photography enthusiasts to share their work.

## Tech Stack (Current Phase)
- HTML5
- CSS3
- Vanilla JavaScript (DOM Manipulation & LocalStorage)

## Project Setup (Localhost)
1. Clone this repository into `C:\xampp\htdocs\framespace`.
2. Start Apache in XAMPP Control Panel.
3. Open your browser and visit `http://localhost/framespace`.
